## 2026-11-06（第十五轮）· 来源：口头需求（对标剧拆解：第 1 集和付费卡点集的格式）

### 字段

- 新增｜对标剧拆解 · 每集｜`EpisodeBreakdown.dims?: EpisodeDims`：五个维度 `emotion` 情绪 / `rhythm` 节奏 / `gap` 信息差 / `expect` 期待感 / `thrill` 爽点（`EpisodeDimKey`），各一段文字；只有第 1 集和付费卡点集（一卡和之后的每个付费卡点）有，其余集没有。每项都要具体到某一句台词、某个动作或某个表情（台词用“”，动作、表情用【】引原文）。五项的名字、提示和第 1 集另写的内容在 `EPISODE_DIMS`（constants.ts）
- 删除｜对标剧拆解 · 每集｜`open3s` 前 3 秒、`open30s` 前 30 秒（首集）、`cardPoint` 卡点（付费卡点集）删掉，内容并进五个维度：前 3 秒 / 前 30 秒写进第 1 集节奏的开局切入方式，钩子、卡点写进节奏（卡在哪、集末定格）和期待感（留下的钩子）。存储升到 v19：第 1 集和付费卡点集去掉这三个字段、清空这几集的 `scenes`，`dims` 按导入的原文重新拆一遍补上（已有的不动）；原来 v16 给一卡之后的付费卡点集补卡点和细拆这一步一并去掉
- 改动｜对标剧拆解 · 每集｜`scenes` 逐场细拆只拆第 1 集和一卡之间的几集（原来是第 1 集到一卡和之后的付费卡点集）；剧本仿写、视频转剧本一样拆（原来视频转剧本第 1 集只拆开场）

### 页面与功能

- 改动｜对标剧拆解 · 冲突主线 · 内容简介｜每集的「走向」改叫「集纲」（字段仍是 `flow`）；本段梗概下面「每集走向」、提示、依据说明里的叫法一起改
- 改动｜对标剧拆解 · 冲突主线 · 内容简介｜第 1 集和付费卡点集改成「集纲 + 五个维度」：集纲下面依次是情绪、节奏、信息差、期待感、爽点五栏，可直接改；五栏一块上底色（首集紫、付费卡点橙）。原来首集的前 3 秒 / 前 30 秒 / 钩子三栏、付费卡点集的卡点一栏，以及这几集的核心台词和逐场细拆去掉
- 新增｜对标剧拆解 · 五个维度｜情绪写怎么起伏，不用数字（如「期待 → 憋屈 → 憋屈到顶 → 回了口气」）、哪一句哪个动作压下去哪里放出来、集末停在什么情绪、属于实际释放 / 部分释放 / 悬念反弹 / 无效积压 / 情绪积压；节奏写本集几场、每段快 / 慢 / 卡、哪段写透哪段一笔带过、集末定格在谁的什么画面和表情（第 1 集另写开局切入方式：第一场戏、前 3 秒 / 前 30 秒的画面，背景和底牌在哪交代）；信息差写新建立、推进或揭破哪条、谁知道谁不知道、属于等主角出手 / 替主角急 / 一起猜（第 1 集另写全剧最大的底牌）；期待感写画了什么饼、怎么加码、兑现程度（完全满足 / 半满足 / 差一点 / 失控反转 / 未兑现）、集末钩子（第 1 集另写全剧总期待）；爽点写铺垫 → 出手 → 确认（谁有什么反应）→ 赢回什么，标级别 T1 大爽 / T2 中爽 / T3 微爽 / 卡点释放 / 无
- 改动｜对标剧拆解 · 冲突主线 · 内容简介｜第 1 集和一卡之间的几集照旧是集纲 + 核心台词 + 逐场细拆；左边目录第 1 集标「首集」，中间几集标「细拆」
- 改动｜对标剧拆解｜拆解进度最后一步改成「逐集写集纲，首集和付费卡点集拆五个维度」
- 改动｜示例剧本｜第 1、2、5、7、9 集（首集和付费卡点集）的集纲和五个维度按格式手写（`SAMPLE_FLOWS` / `SAMPLE_DIMS`）；第 1 集的逐句细拆不再用，第 2 集的只在立项登记的一卡更靠后时用
