# StoryPlay 基础设定下拉选项存档（供剧本 Agent 参考）

> 对象：https://storyplay.cn（StoryPlay·AI 短剧剧本创作平台）的「题材类型 / 核心设定 / 风格元素」等基础设定下拉框
> 方法：登录后在页面内调用只读接口 `GET /api/v1/script/adapt/<类型>/basic-setting/option`，抓取时间 2026-11-03（北京时间 11-04），不消耗点数
> 规模：5 套选项，共 2103 项；原始 JSON 见 `docs/storyplay-options/`
> 用途：只作参考词表，对方平台可能随时调整选项
> 11/4 起：原型故事架构的「题材类型 / 风格元素」用这里的欧美、日本、韩国三套（日韩清洗后合并），核心设定不用；清洗结果和记录在 `docs/storyplay-options/clean/`，见文末第 8 节

## 1. 字段与标签对应

三个下拉框对应项目里 `basicSetting` 的三个字段，标签名随短剧类型变化（前端 `Oi()` 按同样规则解析模型输出里的 `<标签>`）：

| 字段 | AI 类型（AI短剧、欧美/日本/韩国 AI短剧） | 真人实拍类型 |
| --- | --- | --- |
| `timePeriod` | 题材类型 | 时代背景 |
| `storyCategory` | 核心设定 | 题材类型 |
| `storyType` | 风格元素 | 核心设定 |

另有第 4 个字段 `genderOrientation`（目标受众），不在这几个接口里。

海外真人实拍和对应地区的 AI短剧用同一个接口，选项相同，只是标签名换成真人实拍那一套。

## 2. 和提示词的关系（逆向结论摘要）

- **直接进提示词（已确认）**：在「灵感策划 / 改写策划」里，用户选的标签被前端原样拼进请求文本 `【创作标签】目标受众：… 题材类型：… 核心设定：… 风格元素：…`，再接 `【创意描述】`；同一类选了多个用"，"连接。
- **存进项目（已确认）**：选定方案后，这几项写入项目的 `basicSetting`，后续人物、集纲、正文请求只传项目 ID，由服务端读取（是否拼进每一步的提示词无法从前端验证）。
- **未确认**：服务端提示词是否内置整份清单、让模型只能从中选。前端不发送清单，也不校验模型输出是否在清单内。
